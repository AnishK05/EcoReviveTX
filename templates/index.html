EcoReviveTX: Ecological Restoration Analysis Tool

EcoReviveTX provides data-driven tools to support ecological restoration projects across Texas ecosystems. Our platform uses machine learning models and environmental simulations based on research adapted from Wang et al. (2020), which examined soil organic carbon and nutrient dynamics in restoration sites. These tools help predict restoration timelines and model ecosystem responses to environmental conditions, enabling informed decision-making for Texas Parks and Wildlife Department staff, park rangers, and restoration practitioners.

Machine Learning Prediction Tool

Predict restoration outcomes using trained models. This tool can estimate: (1) Restoration Time - the number of years required for ecosystem recovery, or (2) Soil Carbon Response (lnRR.SOC) - the natural log of the response ratio for soil organic carbon accumulation.

Environmental Simulation Tool

Run computational simulations to model ecosystem dynamics under different environmental conditions. Choose between: (1) Basic Ecosystem Model - deterministic simulation of restoration trajectories, or (2) Monte Carlo Simulation - probabilistic modeling with uncertainty quantification across multiple scenarios.
